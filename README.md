# TTS Bot

Каркас бота на aiogram для озвучки текста через ElevenLabs.

В `bot.py` настроены диспетчер Telegram, переменные окружения для ключей и голоса, регистрация команд `/start`, `/voice`, `/voices` и `/setvoice`. Обработчики команд, синтез речи и отправка аудио оставлены заглушками.

## Запуск

Точка входа запускает Telegram polling, но бот отвечает только после реализации обработчиков. Рабочей озвучки в публичной версии нет. Формат переменных указан в `.env.example`.
